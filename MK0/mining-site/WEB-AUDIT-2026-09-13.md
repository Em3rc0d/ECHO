# Web Audit — 2026-09-13

**Status:** `CERTIFIED_MK0_SNAPSHOT`  
**Scope:** public evidence available for ECHO pre-build decisions.

## Method

Priority: standards/official docs -> original papers/repos -> official dataset releases -> related-system primary docs -> secondary sources only for context. A web source can establish an external fact; it cannot produce ECHO-specific empirical performance.

## AI/model evidence

`EV-AI-001` TensorFlow YAMNet transfer-learning documentation supports YAMNet as an AudioSet-pretrained MobileNetV1 path with mono 16 kHz waveform input, overlapping analysis frames in the referenced implementation and 1024-dimensional embeddings usable for transfer learning.

`EV-AI-002` PANNs paper/repository supports Cnn14 and related AudioSet-pretrained representations as a strong CNN challenger.

`EV-AI-003..006` AST, HTS-AT, PaSST and BEATs primary publications/repos establish viable transformer/self-supervised alternatives; they remain extended candidates pending exact runtime/license/benchmark evidence.

## Dataset evidence

`EV-DATA-001` AudioSet official site documents a large human-labeled ontology/media-index dataset used by YAMNet/PANNs pretraining. ECHO treats metadata/ontology licensing separately from underlying YouTube media rights.

`EV-DATA-002` FSD50K official Zenodo release documents 51,197 clips, 200 classes, 108+ hours and multilabel annotations with per-clip license metadata; this directly motivates asset-level license admission.

`EV-DATA-003` SONYC-UST release provides real urban sensor-network/multilabel evidence and motivates source/site-aware evaluation.

ESC-50, UrbanSound8K, MIMII and DCASE/DESED contribute benchmarks, confusers or evaluation methodology but are not assumed to represent the deployment domain.

## Taxonomy evidence

AudioSet ontology includes acoustic concepts relevant to the selected v1 targets: shatter, siren/alarm hierarchy, fire alarm, vehicle horn/honking and tire squeal. Ontology presence supports class plausibility but does not prove that every dataset clip maps cleanly to ECHO labels.

## Streaming evidence

ONVIF Profile T/media documentation supports an interoperable camera-media path where devices implement the profile. FFmpeg and GStreamer docs establish practical RTSP decoding/transport options. The exact professor camera remains external because standards cannot prove device implementation.

## Pub/Sub evidence

MQTT 5.0 OASIS specification establishes QoS semantics; QoS1 is at-least-once and therefore compatible with duplicate delivery. Eclipse Mosquitto is a lightweight open-source MQTT broker. Frigate docs provide an operational precedent for camera/audio events and MQTT topics.

## Privacy/compliance evidence

Peru ANPD sources establish the applicable personal-data framework and videovigilance-related guidance/context. ECHO responds with minimization, no continuous ASR/speaker ID and a field authorization/retention gate. This repository does not claim to replace legal review.

## Certified synthesis

Internet evidence is sufficient to freeze a replay-first, RTSP-capable, multi-source-by-contract architecture and A/B/C benchmark. It is insufficient to certify model winner, thresholds, camera compatibility, field distance/SNR, capacity or final SLOs.
