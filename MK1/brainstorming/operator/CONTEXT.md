# Operator context

User directive, 2026-10-26: implement an integrated, visually strong acoustic
command center, persistence, MQTT gateway, PWA, push and optional VPS setup.
Implementation autonomy is authorized; no tests, runtime validation, production
deployment, automatic CI or merge is authorized in this increment.

The fixed promise is: “Sistema inteligente para la detección y clasificación de
eventos acústicos en ambientes mediante inteligencia artificial”.

The operator's problem is finding the relevant source and its evidence without
watching every camera. Video is contextual support. Current field robustness is
open, so the useful immediate increment is a transparent diagnostic surface,
not a claim that field alerts are now accepted. Three classes only. No VIGIA/map.

The user expects complete modules and a reviewable Git delivery, not a new
planning-only milestone. Empirical gates must remain distinguishable from
implementation decisions. ADR-001 closes the implementation choices.
