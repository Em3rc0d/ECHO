# Quarry — Class Mapping

Para cada `echo_label` mantener:

- definición positiva;
- exclusiones;
- source dataset labels;
- parent/child ontology relation;
- ambiguous examples;
- hard negatives;
- multi-label coexistence rules.

Un mapping no es válido sólo por similitud de strings. Debe reflejar el mismo fenómeno acústico observable.
