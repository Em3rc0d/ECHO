# License Inventory — MK2

Inventariar por tipo:

- ECHO source license;
- runtime libraries;
- FFmpeg build/license configuration;
- broker;
- model code;
- model checkpoint;
- dataset metadata;
- individual training assets;
- fonts/UI assets si aparecen.

`open source`, `free` y `publicly downloadable` no son equivalentes. Release gate exige notices y compatibilidad del conjunto realmente distribuido.
