## Rule

This file remains a template until actual MK2 tests produce evidence. Placeholder values must never be mistaken for a release certificate.

## Certification boundary

The certificate covers only the declared deployment profile/model/config/source envelope and event taxonomy. A new major profile/model/taxonomy can require recertification.

## Historical record

Certificates are immutable historical records; a later release supersedes rather than edits the old certificate.
