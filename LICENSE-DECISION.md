# License Decision

**Estado:** `OPEN`

Apache-2.0 es una candidata razonable para el código propio de ECHO, pero no se crea un `LICENSE` definitivo sin decisión del propietario del repositorio.

## Importante

La licencia del código ECHO no reemplaza las licencias de:

- TensorFlow/YAMNet;
- PANNs u otros repositorios;
- pretrained checkpoints;
- datasets;
- clips individuales;
- FFmpeg y dependencias empaquetadas;
- broker/infra componentes.

Antes del primer release se requiere `THIRD_PARTY.md` o equivalente con inventario de componentes y notices aplicables.
